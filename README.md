# E-Commerce Sales & Customer Analysis (SQL)

## Project Overview

This project uses SQL to analyze real-world e-commerce transaction data from an online retailer. The objective is to investigate sales performance, product trends, and customer purchasing behavior to identify meaningful business insights.

## Business Objectives

The analysis will investigate the following questions:

1. What is the overall sales performance of the business?
2. Which products generate the most revenue?
3. Which countries contribute the most to sales?
4. Who are the highest-value customers?
5. How do sales trends change over time?

## Dataset

**Source:** [UCI Machine Learning Repository – Online Retail Dataset](https://archive.ics.uci.edu/dataset/352/online+retail)

The dataset contains transactions from a UK-based online retailer between December 2010 and December 2011.

Key variables include:
- Invoice number
- Product code and description
- Quantity
- Invoice date
- Unit price
- Customer ID
- Country
